# Notification Dashboard - Frontend

This is a premium notification dashboard built with **Next.js** and **Material UI**. It provides students with a real-time "Priority Inbox" for critical campus updates.

## Features

- **Priority Inbox**: Automatically displays the top 10 most critical updates based on category and recency.
- **Global Feed**: Complete history of all campus notifications.
- **Categorization**: Visual icons and colors for Placements, Results, and Events.
- **Unread Tracking**: Persists viewed status in `localStorage` with visual "Unread" markers.
- **Responsive UI**: Fully optimized for mobile and desktop viewing.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **View Dashboard**:
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Material UI (MUI)
- **Language**: TypeScript
- **State Management**: React Hooks (useState, useEffect, useCallback)
